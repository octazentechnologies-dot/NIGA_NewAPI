S4 Week 4 API
Host: New-API http://127.0.0.1:5038
Login stays Old-API. Razorpay keys stay in appsettings Razorpay:KeyId, KeySecret, WebhookSecret.
Do not commit those secrets. Empty webhook secret returns 503 GATEWAY_NOT_CONFIGURED.
A visit is marked PAID only by a signature-checked webhook or CollectAtReception.
Client POST /api/Payments/Verify only reads status.

SQL (already applied on HomeoCentrum_Dev):
  ScriptsAndFiles/S4_Week4/Database scripts/01_S4_Week4_Schema.sql

Errors use { success:false, code, message }.
Codes: VALIDATION 400, FORBIDDEN 403, NOT_FOUND 404, CONFLICT 409, WEBHOOK_SIGNATURE 401,
GATEWAY 502, GATEWAY_NOT_CONFIGURED 503, SERVER 500.
