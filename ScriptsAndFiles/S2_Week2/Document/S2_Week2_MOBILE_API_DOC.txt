S2 WEEK 2 — MOBILE APP API DOCUMENT
Date       : 20-Sep-2026
Catalog    : NIGA_NewAPI/ScriptsAndFiles/Homeocentrum_All_New_And_Updated+APIs.xlsx
Database   : HomeoCentrum_Dev  (localhost\MSSQLSERVER25)
Host       : New-API  http://localhost:5038/api   (nigahomeoAPI)
Auth       : Authorization: Bearer <JWT> unless TOKEN = no
Dev OTP    : Development responses include data.devCode (never in production)
Do NOT    : Doctor mobile must NOT call case-taking (clipboard, CenterOfGravity, audio, lab mutate, Rx)
Login web  : Clinic password login stays Old-API POST /api/Account/Login on :5001
Razorpay   : Stays Old-API. Public booking hold is PaymentStatus=PENDING until classic pay.

Every endpoint has USE / HOST / TOKEN / SAMPLE / INPUTS / OUTPUT.
Patient app calls the PATIENT APP FLOW. Doctor mobile calls the DOCTOR APP FLOW and must not call case-taking.
Common for all apps: Old-API POST /api/Account/Login, public doctor list, and care-category chips.

--------------------------------------------------------------------------------
PATIENT APP FLOW (PAT-01 … PAT-15)
--------------------------------------------------------------------------------
  1. GET  /Welcome/Patient                         TOKEN=no
  2. POST /Otp/RequestOtp          Action=Login    TOKEN=no
  3. POST /Account/LoginWithOtp                    TOKEN=no  -> save data.token
  4. GET  /Consent/PrivacyStatus
     if data.granted == false -> POST /Consent/GrantPrivacy
  5. GET  /PatientProfile/Me
     PUT  /PatientProfile/Me
     GET  /mastersAPI/GetLanguages                 (language picker)
  6. POST /Device/Register
  7. GET  /PatientPortal/Home
  8. GET  /PatientPortal/CareCategories            TOKEN=no (chips also work logged-out)
  9. GET  /Public/Doctors  (+ filters)             TOKEN=no
 10. GET  /Public/Doctors/{id}  + /Ranking         TOKEN=no
 11. GET  /Public/Articles  + /Public/Articles/{id} TOKEN=no
  12. GET /Family/Me then GET /Family/Relations then GET/POST /Family
      (do not send ownerPatientId — it comes from the login)
  13. GET /Caregiver/Me then GET /Caregiver/Lookup?contact= then POST /Otp/RequestOtp Action=GrantCaregiver then POST /Caregiver/Grant
      (do not send patientId or caregiverUserId — contact is mobile/email)
 14. POST /Account/Logout                          (must hit server)

--------------------------------------------------------------------------------
DOCTOR APP FLOW (DMO-01 … DMO-06)  — no case-taking
--------------------------------------------------------------------------------
  1. Clinic login is Old-API POST /api/Account/Login  HOST=Old-API TOKEN=no
     OR same New-API LoginWithOtp if the doctor uses mobile OTP.
  2. POST /Device/Register
  3. POST /doctorDashBoard/GetCountApp             today’s queue counts
  4. GET  /Availability/Me
     PUT  /Availability/Me                         online + hours
  5. GET  /Profile/Me  PUT /Profile/Me             optional profile
  6. GET  /AppointmentHistoryNote/GetAllAppointmentHistoryNotes?AppointmentId=
     POST /AppointmentHistoryNote/SaveUpdateAppointmentHistoryNote
     HOST=Old-API. Same as doctor web dashboard Add / View Case Notes.
     Do not use Patient Board Global Search, clipboard, COG, or audio from doctor mobile.
Doctor mobile MUST NOT call clipboard / COG / audio / diagnosis mutate.
