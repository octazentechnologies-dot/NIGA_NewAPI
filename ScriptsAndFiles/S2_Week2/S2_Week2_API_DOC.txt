URL        : GET /api/Public/Doctors
USE        : Public website and patient-app doctor discovery. Lists only
             DirectoryVisible=1 and VerificationStatus=Verified. Used by WEB-03,
             WEB-01, PAT-10, PAT-11.
HOST       : New-API
TOKEN      : no
REQUEST    : query
  q, city, isOnline, teleOnly, minFee, maxFee, pageNumber, pageSize
SAMPLE     : GET /api/Public/Doctors?city=Pune&isOnline=true&pageNumber=1&pageSize=20
INPUTS     : optional filters as above
OUTPUT     : { success, pageNumber, pageSize, totalRecords, data: [ PublicDoctorCardDto ] }
  DoctorId, DisplayName, Qualification, City, ClinicName, ConsultFeeInClinic,
  ConsultFeeTele, IsOnline, Verified, PhotoPath, RankingSummary
